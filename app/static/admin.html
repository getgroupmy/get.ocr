Calling the API

        
Call it from your backend with the client's key in X-API-Key. Do not ship the key inside a mobile or web app. Full reference: /docs.

        
        
curl -s -X POST {BASE}/v1/ocr -H "X-API-Key: $KEY" -F file=@receipt.jpg

        
        
curl -s -X POST {BASE}/v1/extract -H "X-API-Key: $KEY" -F file=@invoice.pdf

        
        
curl -s -X POST {BASE}/v1/jobs -H "X-API-Key: $KEY" -F file=@contract.pdf -F external_ref=doc-1042

        
curl -s {BASE}/v1/jobs/$JOB_ID -H "X-API-Key: $KEY"

        
        
curl -s {BASE}/health -H "X-API-Key: $KEY"

        
Files up to 20 MB. Job results are kept 7 day(s), then deleted. With a webhook URL on the client, a signed ocr.completed call is sent when a job finishes; verify X-OCR-Signature as described in the README.
